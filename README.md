# 🏠 ToolNest

### Useful Tools. One Nest.

ToolNest is a collection of useful browser-based tools designed to make everyday digital tasks easier, faster, and more convenient.

The project brings multiple utilities together in one simple web interface, including document tools, photo tools, QR/barcode tools, NID-related tools, calculators, and other productivity utilities.

---

## ✨ Features

- 🪪 NID Card related tools
- 📄 Document and PDF tools
- 📸 Photo resizing and layout tools
- 🖨️ Passport and stamp photo tools
- 🔳 QR Code generator
- 📊 Barcode generator
- 📷 QR / Barcode reader
- 🎂 Age calculator
- 📅 Bangla date utility
- 🤖 AI prompt clipboard
- 📱 Responsive design
- 🌙 Dark / Light mode
- 🔍 Service search
- ⭐ Favorite services
- 💻 Works directly in the browser
- 🔒 Browser-based file processing where supported

## 🔐 Privacy

ToolNest is designed with privacy in mind.

Where a tool supports browser-based processing, files can be processed directly in the user's browser instead of being uploaded to a server.

> **Important:** Not every service necessarily works in exactly the same way. Please check the individual service before using it with sensitive information.

ToolNest does not require users to create an account for the basic tools.

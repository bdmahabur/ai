Getting started

1. Add files
Use Add Files or drag images/PDFs into the drop area. Choose whether imports go one-per-page or together.
2. Select an item
Click an item on the page or in Project Files to edit it.
3. Position and resize
Drag an item to move it. Drag a corner handle to resize, or enter width, height and position in millimeters. Lock aspect ratio to preserve proportions.
4. Edit and arrange
Use rotate left/right, crop/perspective correction, reset crop, duplicate, delete, center, fit and alignment controls. Use Additional Copies when you need repeats.
5. Manage pages
Create, navigate, duplicate or delete pages using the page controls.
6. Set up the page
Choose A4 portrait/landscape, safety margin and zoom. Use Arrange to lay out items on the current page.

Print tips & notes

For accurate physical dimensions, choose A4 paper and set scaling to 100% / Actual size in the print dialog.
Turn off print headers/footers. Use no margins only if your printer supports it; borderless printing depends on the printer.
For small documents, enter the measured width in millimeters and keep Lock Aspect Ratio enabled to calculate the height proportionally.
Use a test print to verify size and alignment before printing multiple copies.
Keyboard shortcuts work when you are not typing in an input, text area or select field.

Crop & perspective correction

Drag each corner independently. Straight crop keeps a rectangle; perspective crop straightens a photographed page.

Tip: place the four handles on the document's corners, clockwise.

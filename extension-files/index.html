How to Load an Extension in Chrome

Chrome extensions downloaded as ZIP files can be loaded manually with Developer Mode.

1

Download the ZIP file

Click the Download ZIP button above and save the extension file to your computer.

2

Extract the ZIP file

Right-click the downloaded ZIP file and extract it to a normal folder. Keep the extracted folder available on your computer.

3

Open Chrome Extensions

In Google Chrome, open the Extensions page or enter this address in the address bar:

chrome://extensions/
4

Turn on Developer Mode

Find the Developer mode switch on the Extensions page and turn it on.

5

Load the extension

Click Load unpacked, select the extracted extension folder, and click Select Folder.

6

Extension installed

The extension should now appear in Chrome. You can pin it from the Extensions menu in the Chrome toolbar.

Important: Do not select the ZIP file directly in Load unpacked. Extract the ZIP first, then select the folder that contains the extension's manifest.json file.

# Bangladesh Constitution MCQ

Offline/GitHub Pages-ready Bangla MCQ web app.

Files:
- index.html
- style.css
- app.js
- questions.js

Open index.html directly in a browser, or upload all files to a GitHub repository and enable GitHub Pages.

Question bank covers the Constitution's article headings, including inserted article labels such as 2A, 4A, 7A, 7B, 58B-58E, 73A, 92A, 116A, 141A-141C and 145A. Some historical provisions are marked repealed where appropriate.

For legal/exam accuracy, compare the latest official text at Bangladesh Laws before publishing as an authoritative study source.
